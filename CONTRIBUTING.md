# Contributing

Thank you for helping someone learn by building something real.

## Good first contributions

- reproduce a small experiment;
- improve setup instructions;
- add or repair a test;
- investigate one documented failure case;
- clean or validate a small dataset sample;
- improve a figure or explanation; or
- propose a sharply scoped experiment.

## Working agreement

1. Start with a clear, finishable milestone.
2. Ask before publishing private information or unfinished private work.
3. Use branches and pull requests when practical.
4. Explain what changed, what you tested, and what remains uncertain.
5. Credit collaborators and sources accurately.
6. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Access

Public repositories are readable by everyone. Direct collaborators may receive **Write** access; **Admin** access is reserved for owners and exceptional maintenance needs. Other contributors are welcome to fork a public repository and submit a pull request.

Never commit passwords, access tokens, private keys, recovery codes, proprietary data, or personal data that has not been approved for publication.
